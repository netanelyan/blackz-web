# blackz-web

אתר התדמית והמכירה של BlackZ - עמוד יחיד, סטטי, עברית RTL.

הכול נמצא בקובץ אחד: `index.html`. אין תלויות, אין שלב build, אין בקשות רשת חיצוניות.
אפשר להעלות אותו לכל אחסון סטטי (Netlify / Cloudflare Pages / GitHub Pages / כל שרת).

## מבנה העמוד

| | |
|---|---|
| Hero | מה BlackZ עושה + קריאה לפעולה |

| **חלק 02 - השירותים** | מה אנחנו עושים · החבילה המלאה · תהליך · מגבלות · שאלות · יצירת קשר |

## מה צריך לערוך

### 1. מספר הוואטסאפ (חובה)

בתחתית הקובץ, בתוך תגית `<script>`:

```js
const WA_NUMBER = '972500000000';   // ← להחליף במספר האמיתי
```

פורמט בינלאומי, בלי `+` ובלי מקפים. `050-1234567` ← `972501234567`.
המספר הזה מזין את **כל** כפתורי הוואטסאפ בעמוד - עורכים במקום אחד בלבד.
כל עוד המספר הוא פלייסהולדר, מופיעה אזהרה בקונסול של הדפדפן.

### 2. שאר הפלייסהולדרים

כל דבר שצריך למלא מסומן בקוד כ־`[כך]` ומוצג באתר עם מסגרת מקווקוות כתומה.
חיפוש `class="ph"` בקובץ ימצא את כולם.

### 3. צילומי מסך של המיזמים

כרטיסי המיזמים בנויים כחלונות דפדפן. כל אחד מצפה לקובץ תמונה:

```
shots/hashofet.jpg
shots/clutchstore.jpg
shots/tiyulplus.jpg
shots/brickdealil.jpg
```

יחס מומלץ: 16:10, רוחב 1200px ומעלה. כל עוד אין קובץ - מוצג פלייסהולדר מעוצב.
מי שרוצה לשמור על קובץ בודד לגמרי יכול להמיר את התמונות ל־base64 ולהדביק ב־`src`.

### 4. עיצוב ומיתוג

כל הצבעים, הפונטים והמרווחים מוגדרים כמשתני CSS בראש הקובץ, בתוך `:root`.
לשינוי צבע המותג - משנים ערך אחד: `--c-accent`.

**הלוגו** מגיע בשלושה מקומות, וכולם מאותו וקטור:

| קובץ | שימוש |
|---|---|
| `logo.svg` | קובץ הלוגו העצמאי, לבן על רקע שקוף |
| `favicon.svg` | האייקון בלשונית הדפדפן - שקוף, מתהפך לפי ערכת הצבעים של הדפדפן |
| `index.html` | מוטמע כ־`<symbol id="blackz-mark">` בראש ה־`<body>` |

בתוך העמוד הלוגו מצויר ב־`currentColor`, כך שהוא לובש את צבע הטקסט של ההדר
ומקבל את צבע המותג במעבר עכבר. לשינוי צבע הלוגו - משנים את `.logo__mark`.

> החלפתם את הלוגו? צריך לעדכן גם את ה־`<symbol>` בתוך `index.html` וגם את
> שני קבצי ה־SVG. הם לא מסונכרנים אוטומטית.

### 5. פונט

האתר משתמש ב־[Arimo](https://fonts.google.com/specimen/Arimo), משובץ בתוך הקובץ
כ־base64: שני תת־קבצים (עברית ולטינית), גופן משתנה במשקלים 400-700, כ־31KB בסך הכול.
אין בקשת רשת - הפונט נטען מיד וגם בלי אינטרנט. רישיון: Apache License 2.0.

להחלפת הפונט: מוחקים את שתי הגדרות ה־`@font-face` בראש ה־`<style>` ומעדכנים את `--f-sans`.

> Arimo מגיע עד משקל 700, ולכן `--fw-black` מוגדר ל־700 ולא ל־900.

### 6. טופס יצירת קשר

כברירת מחדל הטופס פותח שיחת וואטסאפ עם הפרטים שמולאו - עובד מיד, בלי שרת.
למעבר לשליחה במייל: ההוראות המלאות מופיעות בהערה ליד הטופס בקובץ.
