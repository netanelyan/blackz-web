# צילומי מסך של המיזמים

כאן נכנסים צילומי המסך שמוצגים בתוך חלונות הדפדפן בעמוד.

| קובץ | אתר |
|---|---|
| `hashofet.jpg` | https://hashofet.com |
| `clutchstore.jpg` | https://clutchstore.net |
| `tiyulplus.jpg` | https://tiyulplus.com |
| `brickdealil.jpg` | https://brickdealil.com |

**יחס מומלץ:** 16:10 (למשל 1600×1000). רוחב 1200px ומעלה.
צלמו את החלק העליון של העמוד — זה מה שנחתך אם היחס לא מדויק.

כל עוד קובץ חסר, החלון מציג פלייסהולדר מעוצב במקומו ולא נשבר.

> רוצים לשמור על קובץ HTML בודד לגמרי? המירו כל תמונה ל־base64
> והדביקו ישירות ב־`src` של התג `<img>` המתאים ב־`index.html`.
